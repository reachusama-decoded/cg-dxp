v1.11.0 — dbt Unit Testing

July 27, 2026

This release brings unit testing into your dbt build loop. The new /dbt-unit-test skill generates a unit-test suite for a dbt model — mocking the upstream inputs and asserting the expected outputs — so you can cover model logic without hand-writing fixtures.

In this release:

  • New skill — /dbt-unit-test generates unit tests for a dbt model, mocking upstream inputs and asserting expected outputs
  • Updates & enhancements — local Airflow deploy, plus RFD authoring and publishing improvements
  • Coming soon — newly approved standards for pipeline testing and containerization

1. /dbt-unit-test — Unit Tests for Your dbt Models

Point /dbt-unit-test at a dbt model and it generates a full unit-test suite for you — inspecting the model’s SQL and its upstream ref() / source() dependencies to synthesize input fixtures and the expected results, then emitting them as pytest-based tests. You cover model logic without hand-writing a single fixture.

The practical companion to the tiered testing strategy ratified in v1.10.0 — test generation now lands directly in the Phase 4 build loop. If you build dbt models, it’s your fastest path to model-logic coverage.

Thank you to AGGB for contributing this skill.

2. Updates & Enhancements

  • /deploy-airflow-local — run your data product’s DAG locally with astro dev start, extending the Phase 4 build loop from Databricks bundles to Airflow orchestration in your own environment
  • rfd-authoring — a contributor skill that scaffolds new RFDs with the right structure and metadata
  • All ratified RFDs now published on main — every accepted RFD is rendered for easy reference, with author initials normalized

3. Coming Soon

Two standards were just approved and will shape upcoming skills and guidance:

  • Testing strategy (RFD 0018) — a tiered unit / integration / data-quality model that will steer upcoming test tooling across the lifecycle
  • Containerization guide (RFD 0008) — standards for building container images on the corporate network, sourcing from internal mirrors

Thank you to DMRS (RFD 0018) and GPLN (RFD 0008) for authoring these.
