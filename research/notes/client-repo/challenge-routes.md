## Environment facts that bite in the room

- Catalyst is a Copilot plugin installed from the `cg-open-itg/catalyst` marketplace via VS Code user settings (`chat.plugins.enabled`, `chat.useAgentSkills`, `chat.plugins.marketplaces`), then `/plugins` → enable AI Catalyst. Needs GitHub team membership; Cohort 7 had several "repo not found" cases on Day 1.
- Dev container: Docker Desktop role `CPZ_INF_BB00000003_Docker_Desktop_User`; first open takes minutes; `dpc-check` must print green gates; Databricks is OAuth-first (`mise run setup:databricks`, browser login; PAT fallback `--pat`). Windows hosts need Docker Desktop in Linux-containers mode.
- Astro must be started **after** Databricks setup (it captures env at boot); cold-start symptom is an empty catalog name in the Cosmos import error; fix is a new terminal plus `astro dev restart --wait 5m`. The Airflow UI URL is per project (printed by astro), not a fixed `localhost:8080`.
- `BashOperator` and friends are blocked by CG's cluster policy; DAGs need `usage-id` and `cost-center` tags.
- `DBT_HOST` collides with `dbt docs serve`; pass `--host 127.0.0.1 --port 8081`.
- A learner-facing troubleshooting guide exists (`.devcontainer/TROUBLESHOOTING.md`, 23 KB) and a dozen RCAs under `docs/rca/`.
