1. /validate-dbt — Pre-Deploy dbt Validation Gate

A read-only gate that runs before you deploy — it never runs, builds, materializes, or edits a model. Point it at your dbt project and it checks three things against the resolved target: the models compile (Jinja, ref()/source(), macros, catalog/schema vars), the schema diff is additive rather than breaking (no dropped, renamed, or narrowed columns), and your tests resolve (declared primary keys carry not_null + unique). It ends with a single grep-able VERDICT: line.

The quickest way to catch a breaking schema change or a non-compiling model before it reaches Databricks — the read-only counterpart to /validate-dag.
