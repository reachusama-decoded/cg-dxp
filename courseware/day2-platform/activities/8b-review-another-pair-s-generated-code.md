# Activity 8b — Review another pair's generated code

*Day 2 · Pairs, swapped · 20 minutes*

Exchange your contract and one small piece of generated dbt or Airflow code with another pair. Spend five minutes explaining the intended behaviour, ten reviewing, five discussing. As the reviewer: trace one requirement or mapping rule into the code; find one assumption about keys, nulls, dates or scheduling; suggest a concrete check and say what should happen if it fails.

**Produce**

- The line(s) that implement one rule
- One assumption the code makes that the contract does not state
- One check, and the action on failure

**Debrief questions**

- Did the code and the contract disagree anywhere?
- Which assumption would have reached production unnoticed?
