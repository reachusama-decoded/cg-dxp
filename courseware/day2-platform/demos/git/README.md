# Day 2 Git demo

The six steps of the anchor's Git and GitHub section, on a throwaway repository and runnable in a terminal: a repository and a first commit; an edit with `git status` and `git diff`; a branch and a commit on it; the merge back into `main`; a secrets file hidden by `.gitignore`; `git restore` and `git revert`.

```bash
bash demo.sh
```

It recreates `sandbox/` (gitignored) on every run and needs only `git`. The pull request half of the demo is done on screen from the dev container, on the training repository: branch, push, the pull request page, a review comment, the checks.
