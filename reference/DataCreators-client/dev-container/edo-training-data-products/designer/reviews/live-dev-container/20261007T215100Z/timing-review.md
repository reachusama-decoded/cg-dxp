# Timing boundary

The 12 phase estimates remain unpiloted. Tool/agent durations are in the accepted-local verification-results.json and reconstruction/local-classroom-rehearsal.json; they are not junior learner completion times. Installation, first capture/browser setup, cached dbt builds and recording holds are separate from learner thinking time. No arbitrary time target or curriculum reduction was applied. Classroom warehouse/startup waits, memory use and Docker image cache behavior remain unmeasured until the real runtime. Local rehearsal disk use is recorded in its JSON.
