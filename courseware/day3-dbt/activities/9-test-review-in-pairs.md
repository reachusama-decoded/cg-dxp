# Activity 9 — Test review in pairs

*Day 3 · Pairs · 10 minutes*

Swap one mapping rule and the test that guards it with the person next to you. The reviewer proposes a wrong result the pipeline could produce: a duplicated join, a missing dated FX rate, a changed unit. Decide together whether the test would catch it. Agree one improvement and write down the expected failure.

**Produce**

- One rule, its test, and a wrong result the test would or would not catch
- One improvement (a new test, a tightened test, or an independent check) and the failure it should produce

**Debrief questions**

- Which wrong results would have passed every test in the project?
- What value did you check without using the model that produced it?
