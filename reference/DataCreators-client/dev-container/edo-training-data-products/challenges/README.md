# Training challenges

Start with [v2 challenges](v2/README.md) for the current Portfolio Analytics projects; use the [CG guide](cg-public-products/README.md) for Friday. Each tool has phase instructions, an independent starter, hints and evidence checks.

From the prepared training project root:

```bash
mise run challenge:v2:prepare dbt phase-one-certified
mise run challenge:v2:verify-starter dbt phase-one-certified
```

Open the copied attempt and complete the phase tasks before running its completion verifier. Follow [shared runtime setup](v2/runtime/portfolio/SETUP.md) for Databricks and Astro access. Each phase states its prerequisites and workspace paths.

## Earlier exercises

Version 1 contains the earlier numbered route and is retained in the authoring workspace and separate instructor archive. `mise run challenge:verify <NN>` and `challenge:reset <NN>` select v1; they do not select current v2 tasks.

Use earlier exercises only when assigned as historical practice. Their setup and results do not establish completion of the current Databricks/Astro projects. Runnable answers are provided separately by the instructor.
