Capstone Project
Location and objective
• The project is in folder 4, under challenges in the dev container, and is named
  capstone.
• The main task is to work in table groups to reverse-engineer the project s
  source-to-target mappings.
• Review the provided data and the tables to be produced; determine the
  required output tables and relevant STTM rules.
• The project data and materials were generated with ChatGPT and revised
  during attempts to make the project work in the repository. Some details may
  therefore be confusing or inconsistent.
• The instructor said they had spent time rationalizing the project but cautioned
  that additional AI-generated revisions had been made.
Terminology and model context
• Terms such as portfolio and fund may have meanings that differ from those in
  the CD model.
• In particular, portfolio does not refer to multi-manager portfolio construction.

Suggested project documentation
• A PRD, data contract, or similar documentation would be useful to produce
  during the initial work.
• This was presented as a desirable outcome, rather than a firm requirement.
