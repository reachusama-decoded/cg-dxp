# RFDs (Requests for Discussion)

RFDs are how we propose, discuss, and record engineering decisions.

## Process

1. **Reserve** a number and create a branch (`rfd/NNNN`)
2. **Write** your RFD in `rfd/NNNN/README.md` using the [template](0000/README.md)
3. **Open a PR** to `main` when ready for feedback — set state to `discussion`
4. **Discuss** on the PR with line-by-line review and threaded comments
5. **Merge** when discussion converges — set state to `published`

See [RFD 1](0001/README.md) for the full process, states, and guidelines.
