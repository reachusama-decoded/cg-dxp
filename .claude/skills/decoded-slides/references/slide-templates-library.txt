This document has been designed to help anyone at Decoded to create consistently simple, excellent presentations and brochures. 

It’s designed as both a set of guidelines and a library of select templates to be copied, edited and deployed.

Some guidance on layout
Creating a document to be PRESENTED from? (Talks, presentations, high-level proposals, etc.)

Use the presentation format. It’s designed for minimal text and visual information.
Creating a document to be READ? (Brochures, reports, long-hand proposals, etc.)

Use the brochure format. It’s designed to incorporate more space for text.

There are six universal design principles which help us create globally consistent, simple, helpful documents. 

#1 Typeface
Text is set in Work Sans, Normal weight, or Semi-Bold for emphasis.
#2 Type size
Text in Work Sans as standard is set in 8pt, 10pt, 12pt or 14pt. 
Titles in Work Sans as standard are set in 14pt. 
#3 Line spacing
Small sizes (10pt) use 1.3
Larger sizes (15pt or above) use 1.15
#4 Key colours

Using ‘Work Sans’


As a general rule, Work Sans should be used for all standard copy and text. 

When used, it should always be in sentence case (i.e. not all caps), black and set in Light, Normal or Semi Bold. 

On white or light coloured backgrounds, it should be set in black. 

On black or dark coloured backgrounds, it should be set in white.

How to change the weight of your typeface in Google Slides


Select the text you’re setting the type weight for. 

For Work Sans – select the font menu in the toolbar, select Work Sans. Then set the type weight to either Light, Normal or Semi Bold.  

















 

How to change line spacing in Google Slides


Select the text you’re setting the line spacing for. 

Then hit the Line spacing button in the menu bar. 

Then set the line spacing to Custom: 1.3 in the dropdown. 
















 

Use simple shapes, outlined icons and logos on transparent backgrounds. 


Use simple geometric shapes. Generate these using the ‘Insert > Shape’ tool in Slides.

Use icons with a fine outline. thenounproject.com is a good resource (details in Keeper)

If you’re using a third-party logo, float it on top of a simple light grey square or rectangle for neatness. Make sure the logo is in PNG format, with a transparent background.

Stick to the Decoded colour palette at all times. 


Where possible try not to have multiple different colours on a single page. 

When multiple colours can be useful is creating distinctions between information which can, on the face of it, look similar, for example different curricula, or products.

Only use flat colours, only at 100% opacity. 

The main Decoded Yellow (#fef800) is incredible powerful and should be used sparingly on the page. Large blocks of this colour can be overwhelming.

There are some design choices to avoid altogether. 


When using an icon, select one which is a relatively fine outline only. Avoid solid icons. 

Stick to the colours in the Decoded palette, and avoid adding complexity: that means no gradients, no translucency.
