# Activity 9 — Test review in pairs

*Day 3 · Pairs · 10 minutes*

Pick one test from your project and show it to your partner. Together, name one wrong result that would still get past it. Agree one extra test that would catch it.

**Produce**

- One test, and one wrong result it would miss
- One extra test that would catch it

**Debrief questions**

- Which wrong result would have passed every test in your project?
