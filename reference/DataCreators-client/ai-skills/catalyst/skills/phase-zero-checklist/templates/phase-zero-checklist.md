# Phase Zero Checklist

Verify that the foundational conditions for the data product lifecycle are in
place before entering Triage. These are organizational pre-requisites — not
repeated per product, but confirmed each time a new product request is raised.

---

## Roles

| # | Condition | Met | Name / Reference | Notes |
|---|-----------|-----|------------------|-------|
| 1 | A **Data Owner** is identified, informed, and willing to sponsor the request | [ ] | | |
| 2 | At least one **Data Product Creator** with sufficient capacity is available to support Discovery | [ ] | | |
| 3 | A **Data Product Manager** (or equivalent: technical lead or product owner) is identified and available to lead requirements analysis | [ ] | | |
| 4 | **Data Stewards** relevant to the domain are identified | [ ] | | |

---

## Organizational Infrastructure

| # | Condition | Met | Reference | Notes |
|---|-----------|-----|-----------|-------|
| 5 | An **organizational demand tracker** exists and is actively maintained (the demand-tracker-entry.md template is not a substitute) | [ ] | | |
| 6 | The **approved pattern registry** is accessible and current (required to enforce Phase 3 architecture gate) | [ ] | | |
| 7 | The team has access to the **Catalyst repo** and understands the RFD process | [ ] | | |
