# Activity 11 — Explain a failure and repair

*Day 4 · Pairs, then swap · 15 minutes*

Write a short note about the Airflow failure and repair you ran today (or the prepared example if your environment was blocked): the affected run, the useful error, the cause, the action taken, the output check, and anything still unresolved. Swap notes with another pair for five minutes: could they locate the run and explain what happened from the note alone?

**Produce**

- The note, using the template below
- The other pair's verdict: could they find the run?

**Debrief questions**

- Which line of the note was the most useful to the reader?
- What did you have to go back to the UI to find?
