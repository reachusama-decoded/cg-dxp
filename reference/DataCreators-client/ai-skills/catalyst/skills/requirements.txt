# NOT a pip requirement -- deliberately commented out.
#
# The Databricks CLI that Catalyst targets is a Go binary versioned 0.2xx
# (`databricks --version` -> v0.287.0), distributed outside PyPI. The PyPI
# package named `databricks-cli` is the *deprecated legacy* Python CLI, which
# stops at 0.18.0. So `databricks-cli>=0.218.0` can never resolve: it asks PyPI
# for a version scheme that belongs to a different artifact. Left uncommented it
# aborted the whole `pip install -r skills/requirements.txt` documented in
# docs/install.md, so a new user installed *nothing* -- the resolver fails the
# entire transaction, not just this line.
#
# The range stays here, in this shape, because /build-preflight reads it as text
# for its tool-version drift check. Install the CLI itself per docs/install.md.
# databricks-cli>=0.218.0,<1.0.0
