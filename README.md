# cg-dxp — Data Creators delivery workspace

Preparation and courseware for delivering Capital Group's Data Creators programme (five days).

| Folder | Contents |
|---|---|
| `courseware/` | **The instructor pack**: one folder per day (run sheet, demos, activities, diagrams, fallbacks), `00-week/` for the week-level guide, `common/` for shared assets, prompts and the demo environment. This is what gets used in the room. |
| `reference/` | Supplied material, read-only: the client training repo and Catalyst skills, the instructor plan, Cohort 7 recordings and notes, the sibling CG Core programme, CG notes. |
| `research/` | Intermediate work: `extracts/` (text of the Cohort 7 PDFs), `notes/` (review notes), `plans/` (decisions, plan drafts), `scripts/` (helpers). Not needed in the room. |
| `.claude/` | Claude skills and settings for working in this folder. |
