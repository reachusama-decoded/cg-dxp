# Your personal AI skill

Create `skills/<your-skill>/SKILL.md` for one task in your own work. Explain when to use it, the required inputs, steps, expected output and limits. State which source evidence it must check.

Use the skill through the instructor’s Catalyst setup. If Catalyst cannot load the file directly, supply its contents as instructions and record that method. Save an actual prompt, result, limitation and revision in `examples/invocation.md`. Remove credentials and sensitive text from that record.

Run the suggested checks yourself and compare claims with source evidence. A saved instruction file without a recorded use does not complete the task.
